# ZETA UI 참고 자료

이 폴더는 ZETA 프로젝트 전용 UI/UX 참고 이미지 보관 장소입니다.

## 넣을 자료
- 채팅 화면 및 말풍선 디자인 예시
- 캐릭터 프로필/선택 화면 예시
- 캐릭터·작품·로어북 설정 화면 예시
- 대화 슬롯, 책갈피, 통계 화면 예시
- 전체적인 색상·레이아웃 참고 이미지

이미지 파일은 이 폴더에 업로드해 주세요. 파일명은 화면이나 기능을 알아볼 수 있게 작성하면 됩니다. 예: `chat-layout.png`, `character-profile.jpg`.

이 저장소와 자료는 MKA23, OH 등 다른 프로젝트와 별개입니다.
